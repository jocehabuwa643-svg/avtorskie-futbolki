Авторские футболки — вышивка и бисер вручную.

Сайт: https://jocehabuwa643-svg.github.io/avtorskie-futbolki/

Статика без сборки: `index.html`, `styles.css`, `site.js`, `404.html`, `manifest.webmanifest`, медиа в `film/`, шрифты в `fonts/`.
Публикация — GitHub Actions (`.github/workflows/pages.yml`): в артефакт копируются только эти файлы и папки.
Пути только относительные (project site).

## Медиа

- `film/b-*.mp4`, `film/f-*.mp4` — ролики глав (1:1 и 4:5). Закодированы в 12 кадров/с с ключевым кадром каждые 3 кадра, скролл их перематывает.
- `film/c-*.mp4` — короткие петли для «Крупно» и подвала, `film/p-*.jpg` — фото для «Крупно».
- `film/s/<ролик>-<n>.webp` — листы кадров тех же роликов (4 кадра в ряд, 12 на лист). Нужны браузерам, которые отдают
  `<video>` собственному плееру (Mi Browser и похожие), и на случай, если ролик не загрузился: кадры рисуются на canvas.
  После замены ролика лист надо пересобрать, а таблицу `SEQ` в `site.js` обновить.
- `film/w-*.webp` — футболки для гардероба, `film/i-*.png` — значки.

Каждая вещь показана один раз в фильме или в «Крупно» и один раз в гардеробе.

## Проверка режима без видео

- `?kino=frames` — принудительно кадры вместо видео (так сайт выглядит в Mi Browser).
- `?kino=video` — принудительно видео и сброс запомненного режима.

## Защита

- Перед каждой выкладкой запускается `.github/check.mjs`: синтаксис скрипта, наличие всех файлов, на которые ссылается сайт,
  совпадение хеша встроенного скрипта с Content-Security-Policy. Если проверка не прошла, на адресе остаётся прежняя версия.
  Вручную: `node .github/check.mjs`.
- Встроенный скрипт в `<head>` менять только вместе с хешем `sha256-…` в мета-теге Content-Security-Policy (проверка подскажет нужный).
- Чужих скриптов, стилей и шрифтов на сайте нет: всё грузится со своего адреса.
- Действия в `pages.yml` закреплены по хешу коммита; обновления присылает Dependabot.
- Точка возврата: тег `stable-2026-10-02` (версия до этих изменений).
