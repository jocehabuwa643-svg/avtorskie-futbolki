Авторские футболки — вышивка и бисер вручную.

Сайт: https://jocehabuwa643-svg.github.io/avtorskie-futbolki/

Статика без сборки: `index.html`, `styles.css`, `site.js`, медиа в `film/`.
Публикация — GitHub Actions (`.github/workflows/pages.yml`), в артефакт копируются только эти файлы и папка `film/`.
Пути только относительные (project site).

- `film/b-*.mp4` — фон на весь экран: модель в футболке, скролл перематывает ролик.
- `film/f-*.mp4` — кадр 4:5 с вещью крупно.
  Оба вида закодированы в 12 кадров/с с ключевым кадром каждые 3 кадра, чтобы перемотка по скроллу была лёгкой.
- `film/c-*.mp4` — короткие циклы для блока «Крупно», `film/p-*.jpg` — фото для него же.
- `film/w-*.webp` — футболки для гардероба: силуэт, ткань этой же вещи и настоящая вышивка на груди.

Каждая вещь показана один раз в фильме или в «Крупно» и один раз в гардеробе.
